## Как создать недостающие цели (для владельца)

`Настройки → Цели → Добавить цель → JavaScript-событие` → «Идентификатор
цели» — имя события **точно как в таблице B**, строчными, с подчёркиваниями
→ название — из столбца «Название для создания» → `Добавить цель`.
Первые достижения появятся через сутки. Программно — этап 06/13, когда
будет решение о праве записи.
