| Событие | Почему |
|---|---|
| `lead_submit_attempt`, `submit_tshirt_order` | попытка ≠ результат; для разрыва хватает автоцели формы |
| `submit_tshirt_order_success`, `submit_tshirt_order_error` | дубли; результат уже в `lead_submitted_tshirt` |
| `reviews_source_click`, `view_tshirt_catalog`, `view_custom_tshirt`, `canvas_send_photo_later` | справочные события, отчётов на них нет |
| 9 DEPRECATED из каталога | не отправляются |
| `purchase` как цель | заявка — не покупка; покупки придут из CRM (этап 06) |

## Как создать цель (для владельца)

`Настройки → Цели → Добавить цель → JavaScript-событие` → в поле
«Идентификатор цели» — имя события **точно как в таблице**, строчными,
с подчёркиваниями → название любое понятное → `Добавить цель`. Первые
достижения появятся в отчётах через сутки. Программное создание через
API управления — этап 05, когда появится токен с правом записи.
