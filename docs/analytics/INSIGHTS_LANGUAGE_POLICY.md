# INSIGHTS_LANGUAGE_POLICY.md

# Языковая политика сигналов (этап 12)

## Статус

```text
IMPLEMENTED 16.09.2026 — crm-new/src/analytics/insights/insights-language.ts: FORBIDDEN_PHRASES, violatesLanguagePolicy(),
hypothesisText(). Проверяется тестом по всем шаблонам детекторов (insights-engine.spec F1–F3) и движком перед записью
каждой карточки (нарушение → ошибка детектора в журнале запуска, карточка не создаётся).
```

## 1. Три части карточки

| Часть | Что это | Форма | Пример допустимого | Недопустимо |
|---|---|---|---|---|
| **FACT** | воспроизводимое число / событие из данных с подписью периода и выборки | числа, даты, знаменатели, p-value, MDE | «Конверсия визитов в заявку: за 26.09–02.10 1,0 % (5 из 500), в предыдущем окне 8,0 % (40 из 500); разница −7,0 п.п.; p = 0,000» | «пользователи стали хуже воспринимать форму» |
| **HYPOTHESIS** | возможное объяснение из сопутствующих проверяемых фактов | всегда «Гипотеза: … Причинность не установлена.», сослагательная форма («может быть одним из факторов», «совпало по времени»), список поддерживающих фактов числами; либо `NO_SUPPORTED_HYPOTHESIS` | «Гипотеза: рост ошибок формы совпал по времени со снижением завершения формы — техническое состояние формы стоит проверить. Причинность не установлена.» | «Причина падения — реклама», «упало из-за Директа» |
| **RECOMMENDATION** | следующее аналитическое или операционное действие для проверки | проверить, сравнить, дождаться, зарегистрировать | «Технически проверить форму и логи приложения за период» | «отключить рекламу», «поменять цену», «откатить сайт» |

Система **не обязана** придумывать гипотезу: если сопутствующих фактов нет — `hypothesis.status = NO_SUPPORTED_HYPOTHESIS`
и текст «Гипотезы нет: сопутствующих фактов, которые могли бы объяснить наблюдение, в данных не найдено.»

## 2. Запрещённые формулировки (регулярные выражения `FORBIDDEN_PHRASES`)

```text
из-за · благодаря · привел(о|а|и) к · привело · вызвал(о|а|и) · причин(а|ы|ой) · доказ(ано|ывает|ал) · следовательно ·
поэтому упал · отпугива… · не нравится · не доверя… · слаб(ый|ая) CTA · плох(ой|ая) дизайн · пользовател(и|я) (стали|перестали)
```

Границы кириллических слов заданы через `(?![а-яё])` — `\b` в JavaScript кириллицу не знает.

## 3. Разрешённые исключения (отрицания причинности)

```text
причинность не установлена · не доказывает · нельзя приписать · не является эффектом · не установлена
```

Исключения вырезаются перед проверкой, поэтому обязательные оговорки («не доказывает связь», «нельзя приписать одному
изменению») не считаются нарушением.

## 4. Обязательные оговорки

- в каждой карточке `causality: 'NOT_ESTABLISHED'` (поле контракта) и заметка качества
  «Сигнал — наблюдение по данным, а не установленная причина: совпадение по времени не доказывает связь.»;
- в UI под заголовком раздела: «…Отсутствие сигналов не означает, что проблем нет.»;
- пустая лента — «Сейчас нет сигналов, требующих внимания» (никогда «всё хорошо»);
- карточки этапа 10 подписаны «вычислено правилом этапа 10», этапа 11 — «вердикт этапа 11 без переинтерпретации».

## 5. Что не является языком сигналов

Психологические объяснения поведения посетителей, персональные рекомендации по клиенту, прогноз выручки как факт,
призывы к бизнес-решениям (реклама, бюджет, цены, удаление страниц, откат) — таких шаблонов нет, и генератор
гипотез строит текст только из перечисленных в INSIGHTS_RULES.md § 5 связок.
